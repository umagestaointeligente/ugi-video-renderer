# LSI Capital — Broker Capability Note R1

Current ChatGPT plugin discovery found market-analysis/data options including Interactive Brokers (IBKR), Alpaca, Longbridge and other market tools, but no currently connected tool in this conversation has been proven capable of safely opening a Brazilian brokerage account and submitting B3 orders end-to-end.

Therefore:
- ACCOUNT_OPENING_AUTONOMOUSLY=NOT_PROVEN
- REAL_BROKER_ORDER_EXECUTION=NOT_PROVEN
- PAPER_PORTFOLIO=AUTHORIZED_FOR_AUTONOMOUS_LEARNING
- REAL_ORDER=BLOCKED_BY_EXECUTION_AND_AUTHORIZATION_GATE

Do not confuse an analysis connector with a brokerage execution rail.
