# LSI Capital — Real Order Authorization Contract R1

Research, ranking, simulation and paper rebalancing may run autonomously.

A real-money order is a separate high-impact action and remains disabled in R1. If a compatible broker execution mechanism becomes available, every real order must surface at least: account/broker, ticker/instrument, side, quantity/notional, order type, price/limit if applicable, estimated fees/taxes when available, thesis, maximum loss/risk rationale, portfolio weight after trade, and source timestamp. The execution mechanism must obtain the authorization required for that specific order before submission.

No standing permission in project documentation overrides this per-order firewall. No broker password, API secret, private key, 2FA token or recovery code may be committed to GitHub, Library learning logs or public endpoints.
