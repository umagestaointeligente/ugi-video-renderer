# UGI PDF MASTER STANDARD

Status: REQUIRED
Canonical reference: Kit_UGI_Priorizacao_Inteligente_PREMIUM_V4_UPLOAD_CANONICO-1.pdf
Purpose: define the mandatory editorial, visual and commercial standard for every paid UGI PDF.

## 1. Product level
Every paid UGI PDF must look and feel like a premium, useful, decision-oriented management product. A plain text report, generic handout or lightly formatted document is NOT acceptable.

## 2. Canonical structural pattern
Use the canonical 18-page kit as the reference pattern for density, hierarchy, visual polish and practical value.

Expected components, adapted to the topic:
- Strong branded cover with UGI identity, premium dark/navy base, warm gold accent, hero image and a clear outcome box.
- Opening page explaining how to use the kit and the first concrete victory/result expected.
- Real-world problem framing.
- Clear conceptual distinctions relevant to the topic.
- At least one proprietary UGI method, score, matrix, framework or explicit operating rule when appropriate.
- Practical scoring/calibration or decision guidance.
- At least one visual matrix/diagram/table.
- Filled example or worked example.
- Conflict/edge-case handling.
- Operational practice for protecting capacity/focus/quality.
- Delegation or accountability guidance when relevant.
- Short recurring ritual/cadence.
- One or more ready-to-copy UGI prompts.
- Master prompt or master operating framework.
- Planning or implementation page.
- Dashboard/measurement page.
- 7-day implementation plan or equivalent adoption path.
- References and continuity/next-level page.

## 3. Mandatory usability
Every tool/framework must end in an observable or executable output. Content must not stop at explanation.

Preferred outputs include:
- checklist
- score
- matrix
- decision rule
- prompt
- table
- plan
- message/script
- owner
- deadline
- evidence of completion

## 4. Visual system
Mandatory characteristics:
- UGI dark/navy header/footer system.
- Gold accent used consistently for emphasis and labels.
- High-contrast typography.
- Clear section titles and subtitles.
- White/neutral content areas with generous spacing.
- Branded footer with UGI name, version/page indicator and product/code where applicable.
- Cards, boxes, diagrams, matrices and structured visual blocks instead of long plain-text pages.
- No clipped text, overflow, overlapping elements or illegible microtext.
- No AI-generated text embedded inside images.
- Visuals must match the semantic content.

## 5. Editorial style
- Portuguese (Brazil), direct and executive.
- Short paragraphs.
- Practical, specific language.
- Avoid generic motivational content.
- Avoid fluff and filler.
- Explain concepts in a way a manager can apply immediately.
- Distinguish fact, rule, recommendation and UGI synthesis when relevant.

## 6. Prompt blocks
Where prompts are used, preserve a standardized block style and include fields such as:
- PAPEL
- CONTEXTO
- TAREFA/OBJETIVO
- CRITÉRIOS/AVALIE
- RESTRIÇÕES
- SAÍDA

Prompt text must be copy-ready and useful without needing the original social post.

## 7. Evidence and references
Where factual frameworks or external principles are used, include concise support/reference lines. Authorial UGI methods must be identified as UGI synthesis/method when appropriate.

## 8. Commercial value gate
Before a PDF can be sold, QA must answer YES to all:
- Does the material solve a concrete management problem?
- Is the value obvious within the first pages?
- Does it contain practical tools, not only explanations?
- Is there at least one visual framework/table/matrix where appropriate?
- Are there copy-ready prompts/scripts/templates when useful?
- Is there a worked example or equivalent application evidence?
- Is there an implementation path or next-step plan?
- Does the PDF visually match the premium UGI master standard?
- Would the buyer reasonably perceive value at the listed price?

If any critical answer is NO: STORE_PUBLICATION_ALLOWED=false.

## 11. Non-acceptable output
Reject automatically:
- plain ReportLab text dump
- generic memo/report formatting
- PDF with only headings and paragraphs
- superficial 2-5 page material for a premium kit when the topic requires depth
- missing visual tools/matrices where relevant
- unbranded cover
- no implementation guidance
- no practical outputs
- no QA review copy
